How should new tabs work?

Bookmarks, notes, to-dos, countdowns, focus timer, habits, clock and weather. Your data stays in this browser profile and is not synced to other devices.

Every new tab opens this address. The extension sends nothing anywhere else and stores only this address (synced with your browser profile).

Moving to a server

Download what you created without a server, then import the file on your server under Settings → Transfer. Importing replaces the server's dashboard and appearance with yours.
